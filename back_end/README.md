# Back-end (FastAPI)

REST + WebSocket-style API for the Steam Game Data Demo. Built with FastAPI, SQLAlchemy 2 (async), Redis, and OpenRouter.

## Endpoints

| Method | Path | Auth | Notes |
|---|---|---|---|
| `POST` | `/api/v1/auth/register` | public | Returns `UserOut`; new users default to `viewer` role |
| `POST` | `/api/v1/auth/login` | public | Returns `TokenResponse` (access + refresh) |
| `POST` | `/api/v1/auth/refresh` | public | Trades refresh token for a new access token |
| `POST` | `/api/v1/auth/logout` | refresh token | Revokes the refresh token |
| `GET / PUT` | `/api/v1/auth/me` | active user | Profile + roles + permissions |
| `PUT` | `/api/v1/auth/me/password` | active user | Change password |
| `GET / POST` | `/api/v1/games` | read / `games_write` | List / upsert |
| `GET` | `/api/v1/games/{steam_appid}` | active user | Game detail |
| `DELETE` | `/api/v1/games/{steam_appid}` | `games_delete` | Admin only |
| `GET / POST` | `/api/v1/games/{steam_appid}/reviews` | read / `reviews_write` | List / create reviews |
| `DELETE` | `/api/v1/games/{steam_appid}/reviews/{recommendationid}` | `reviews_delete` | Admin only |
| `GET` | `/api/v1/dashboard/overview` | active user | Totals (games, reviews, free/paid, devs, languages) |
| `GET` | `/api/v1/dashboard/top-games` | active user | Games ranked by review count |
| `GET` | `/api/v1/dashboard/genres` | active user | Genre distribution |
| `GET` | `/api/v1/dashboard/years` | active user | Release-year distribution |
| `GET` | `/api/v1/dashboard/languages` | active user | Supported-language distribution |
| `POST` | `/api/v1/ai/chat` | active user | Tool-calling chat (Charting + ExecuteQuery) |
| `POST` | `/api/v1/ai/chat/stream` | active user | Streaming chat (text only, no tool) |
| `GET` | `/api/v1/ai/sessions` | active user | List user's chat sessions |
| `GET` | `/api/v1/ai/history/{session_id}` | active user | History of a session |
| `GET` | `/api/v1/ai/charts` | active user | Charts generated by the AI agent |
| `GET` | `/api/v1/admin/roles` | admin | Catalog of roles |
| `GET` | `/api/v1/admin/permissions` | admin | Catalog of permissions |
| `GET / PATCH` | `/api/v1/admin/users/{id}` | admin | List / patch user |
| `POST` | `/api/v1/admin/users/{id}/roles` | admin | Assign role |
| `DELETE` | `/api/v1/admin/users/{id}/roles/{role_name}` | admin | Revoke role |
| `GET` | `/health` | public | Health probe |
| `GET` | `/docs` | public | Swagger UI |

## AI tools

The model can call two tools. Both are exposed only through the chat endpoint; tool calls are validated server-side.

### `charting`

Generate a Chart.js configuration from a chat instruction. The model must reply with JSON of the shape:

```json
{
  "tool_call": {
    "name": "charting",
    "arguments": {
      "chart_type": "bar | line | pie | doughnut | scatter | radar | area | polarArea",
      "chart_title": "Top 10 genres",
      "x_axis_label": "Genre",
      "y_axis_label": "Count",
      "x_rotation": 30,
      "y_unit": "games",
      "series_label": "Number of games",
      "config": { "labels": ["Action"], "datasets": [{ "label": "Games", "data": [1234] }] },
      "source_query": "SELECT ...",
      "notes": "optional"
    }
  }
}
```

The server validates the payload, sanitises Chart.js options, persists the chart to `ai_chart_history`, and returns it to the chat response.

### `execute_query`

Run a read-only SQL query against Supabase. The model must reply with JSON of the shape:

```json
{
  "tool_call": {
    "name": "execute_query",
    "arguments": {
      "sql": "SELECT TRIM(g) AS genre, COUNT(*) FROM (SELECT UNNEST(STRING_TO_ARRAY(genres, ',')) AS g FROM games) t GROUP BY 1 ORDER BY 2 DESC LIMIT 10",
      "limit": 10,
      "params": {}
    }
  }
}
```

The server rejects anything that is not `SELECT` or `WITH`, or that contains forbidden keywords (`insert`, `update`, `delete`, `drop`, `alter`, `truncate`, `copy`, `grant`, `revoke`, `create`, `vacuum`, `analyze`, `refresh`, `set`, `call`, `do`, `explain`, `select into`, ...). It also wraps the query with a hard `LIMIT 500` cap.

## Local development

```bash
cd back_end
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env       # fill in DATABASE_URL, REDIS_URL, OPENROUTER_API_KEY, ...
uvicorn app.main:app --reload --port 8000
```

Open <http://localhost:8000/docs> for Swagger UI.

## Deployment

Two options are documented in detail in the top-level `DEPLOY.md`:

- **Without Docker** (recommended for free-tier VMs): systemd + Nginx reverse proxy, RAM usage < 200 MB.
- **With Docker**: optional `Dockerfile` and `docker-compose.yml` snippet.
